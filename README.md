## ❓ Frequently Asked Questions

### How do I add activities?

Go to the main screen and add or customise activities such as Reading, Homework, or Chores.

### How do I update points?

Tap on an activity and use the + or – buttons to adjust points.

### How do I reset progress?

Go to Settings → Reset Progress.

### Can I customise rewards?

Yes, you can set your own rewards and milestones in the app.
